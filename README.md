# Analysing Spotify DataSet

# Overview

## Dataset File
The dataset "artist_data.csv" provided by Spotify contains information collected in the year 2023. The main variables of the dataset include: Artist names, popualarity score (scaled 0-100), number of followers, Genres associated with artist (6 columns). 

## Tools used
Python was used to analyse the data set and the following packages were installed:
- pandas for data wrangling
- numpy for numerical computations
- matplotlib for data visualtions


# PART 1
## Basic Data Inspection
Contained in the script "basic_data_inspection.py". Basic inspection of the data was performed including:
- How the dataset is structured
- Data types contained in each column
- Computing the number of unique artists
- Ranking top 10 artists by popularity (0-100)
- Ranking top 10 artists by number of followers

Figures (.png) generated by this file:
- "Top_Followers_bar_chart.png"
- "Top_Popularity_bar_chart.png"

## Genres Inspection
Contained in the script "Genres_inspection.py". This file does an analysis based on genres including:
- A function that returns the top 10 artists for a given genre
- Adding a column to the dataset to show the number of genres an artist is associated with
- Finding potential correlations between number of genres per artist and their popularity/number of followers
- Adding a column to the dataset for the log(followers)+1

Figures (.png) generated by this file:
- "Distribution_genres_bar_chart.png"
- "Genres_vs_Popularity_boxplot.png"
- "Genres_vs_followers_boxplot.png"
